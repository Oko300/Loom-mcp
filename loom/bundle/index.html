Connect your workspace

Loom needs the FlowDev VS Code extension to read your project and build your memory. One-time setup — takes about 2 minutes.

Setup steps

1
Get a free token at flowdev.onrender.com/request
2
Install FlowDev MCP from the VS Code Marketplace
3
In VS Code → FlowDev sidebar → paste token → click Connect
4
In Anna → Loom → Settings → Credentials → add your FlowDev token, then click Check Connection below

Your token is stored securely in Anna's credential vault — never in the app itself.
